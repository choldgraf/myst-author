The tour is a small MyST project in [`docs/examples/tour/`](https://github.com/choldgraf/myst-author/tree/main/docs/examples/tour).
Each page has **Try this** boxes that walk you through a feature in the editor.

Open it with the Codespaces or Binder badge on [Get started](../get-started.md), or locally:

```bash
npm run demo          # in the web editor
npm run demo:lab      # in JupyterLab
npm run demo:vscode   # in VS Code
```

Each opens a copy of the tour in a temporary folder, so your edits don't touch the repository.

Start at `index.md` and follow the link under **Next** at the bottom of each page.
The last two pages are for JupyterLab and VS Code.
`notebook.ipynb` shows MyST in a notebook.
`github.md` walks you through cloning a second project into the workspace and pushing a change back to GitHub.

[References](references.md), [Preview](preview.md), and [Directives and roles](directives.md) explain each feature in more detail.
