The tour is a small MyST project in [`docs/examples/tour/`](https://github.com/choldgraf/myst-author/tree/main/docs/examples/tour).
Each page has **Try this** boxes that walk you through a feature in the editor.

Open it with the Codespaces or Binder badge on [Get started](../get-started.md), or locally:

```bash
npm run demo
```

The tour has these pages:

- `index.md`: editing in place, the preview, click-to-source, hints, completion, hover, the page outline, and opening a file by name.
- `live.md`: live preview: editing in place, moving with the keyboard, figures, embeds, tabs, warnings, and find.
- `references.md`: go to definition, following links from the preview, fixing a broken reference, and external references.
- `directives.md`: directive options, directive names, and nested directives.
- `notebook.ipynb`: references in notebook Markdown cells in JupyterLab and VS Code, and live preview in them in JupyterLab.

[References](references.md), [Preview](preview.md), and [Directives and roles](directives.md) explain each feature in more detail.
